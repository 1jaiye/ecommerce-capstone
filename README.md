# E-Commerce Sales Data Pipeline

## Project Overview

This project builds an end-to-end data engineering pipeline
for an e-commerce business.

## Project Objectives

- Extract data from CSV, JSON and REST API sources.
- Validate and clean incoming data.
- Load data into PostgreSQL.
- Perform analytical SQL queries.
- Build a dimensional data warehouse.
- Test and optimize database queries.

## Tools and Technologies

- Python
- PostgreSQL
- SQL
- Git and GitHub
- Visual Studio Code
